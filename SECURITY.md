# Security policy

OrbitDesk AI is a synthetic-data prototype, not a production system.

## Reporting

Please report suspected vulnerabilities privately through the security reporting channel configured for the GitHub repository. Do not include production credentials, personal data, customer records, or exploit payloads containing sensitive information in a public issue.

## Supported version

Only the latest commit on the default branch is supported for prototype maintenance.

## Scope reminder

Before production use, add identity and access controls, durable audited storage, rate limiting, secret management, environment-specific CORS, transport security, monitoring, dependency scanning, and an AI evaluation/safety layer.
